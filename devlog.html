October 21, 2026

Astra and I had an adventure

I used Astra for this. I had it deploy subagents to go through all of the US3D documentation that I supplied it (about 400 pages). It churned for about 20 minutes, before I realized all the subagents were using Astra as well. I paused it and had it complete the task using Sonnet (it used Sonnet 4.6). There are now summaries for all chapters for the agents to reference in the future. In all, it took about 30 minutes and spent about $20.

I went through the Backlog tasks more carefully, and the agent seems to overestimate its capabilities in the breakdown of tasks, so spent some time breaking down the tasks more thoroughly. The new tasks are smaller, and hopefully will not overwhelm the less complex agents. I am currently a bit unsure about whether I would like the documentation references to be broken down into a specialized agent or a skill, since the current plan is to deploy subagents to find the necessary hooks for equations I would like to implement, so they would all ideally be able to quickly navigate the documentation.

October 14/15, 2026

Beginnings of Specialized Agent Implementation + a little Housekeeping

I spent some time to set up backlog and download the subagents extension. I also added the assignments page, so the website should be easier to use to see class progress.

In Backlog, I used GPT’s Sol 6 to plan out my entire project. The current tasks seem reasonable, but I’m sure they will need to be broken down further as the project progresses, as demonstrated by the attempt to build a specialized subagent. I started with Sonnet 5.5 for this, asking it to set up the architecture for the agent, as given in class notes. Issues were immediately encountered in just trying to navigate it to the reference files. I have large manuals that list the hooks for the solver. When pointed to the files to write a SKILL that would reference these files, the agent tried to read them and then broke. The terminal was requesting access to all kinds of things (I’m not sure why), and even after stopping the command, the entire session was unusable and would error after every input.

This leads into the following issue. Current subagent doesn’t work since I don’t think it can actually handle reading through the large pdfs I currently have in my reference library (not uploaded to GitHub). Next steps would be to try to refine the files and cut down all unnecessary fluff by hand or with a more powerful agent. GPT Sol ended up writing the current skills for the specialized agent, but I need to refine my references so that smaller models can handle them cleanly without bugging out again.

September 30, 2026

Figure Recreation and some New Skills

Tried starting out with GPT-Nano, before switching to Terra and Sonnet. Nano would be overly verbose about all the commands I gave it before repeating them back to me when the task was not super clearly specified (poor on my end too, but it was quite unforgiving unlike Terra or Sonnet).

Creating the skills was pretty easy. I used the SKILL.md template this time instead of trying to prompt it from scratch. That was a lot faster. Definitely need to go back and review the TDD skill more carefully, but for now the capabilities seem to match what I have been Googling and seeing thus far. For the recreation of the figure skill, I had it emulate WebPlotDigitizer capabilities.

I then had two independent agents write tests (first) and then recreate a figure from Richard Peterson's "Codesign of Plasma Avoidant and Plasma Embracive Antenna Topologies for Hypersonic Applications." It did a pretty good job in terms of the image looking very similar. It passed all the tests the other agent wrote. A step I should take to examine this more closely is to double check the tests and calculated values further, but that will take a bit to backtrack the math since some of these values were pulled from CFD simulations.

Fixing Skills, Trying out Sandboxing, and Fixing Up the Project Page

Skills: Resolved the issue that pi had been telling me all along, but I wasn't reading the top when it wasn't loading, oops.

I tried playing around with getting it to run commands such as git add . and git commit, not expecting it to work. September 14, 2026

Week 1: Site Creation

Since I have no experience with creating websites, Claude Sonnet 5 did the vast majority of the heavy lifting with the formatting and creation of the pages. I had the agent create the site using html, with the original reference files from the class website Astro files. It ended up deleting them. The easter eggs were remarkably easy for it to implement, requiring only a single prompt.

Changing colors or fonts required multiple prompts, and the agent often insisted that the colors had all been changed one way or another when it had not. The insertion of pictures also had a brief hiccup with paths, although this was more likely due to unspecific prompting on my end.

The animation and easter egg pop ups were quite fun to brainstorm and the agents did a great job. It was definitely faster than doing it on my own, and I was quite impressed with how smooth the process was. Log entries and larger text blocks were manually input.
