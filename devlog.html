September 23, 2026

Fixing Skills, Trying out Sandboxing, and Fixing Up the Project Page

Skills: Resolved the issue that pi had been telling me all along, but I wasn't reading the top when it wasn't loading, oops.

Sandboxing: I have mostly been running pi with nono throughout the class and was somewhat familiar with the fact that it can only access the files within the working directory. I tried playing around with getting it to run commands such as git add . and git commit, not expecting it to work. It is pretty good at finding workarounds and was able to add by using the temp folder. This is something to keep in mind for the future to consider with commands that I wouldn't expect it to be able to run. Also tried to make a separate profile with the slides commands, but that one had the ability to read+write in my config files so that got scrapped pretty early on; this is definitely something to look into again.

Updating Website: Switched to Opus to evaluate some concerns and break down fixing the website aesthetics into bite-sized tasks, which it did well although it cost ~$2 to go through 10 aesthetic concerns. Ultimately I decided I like the 2009 blog look. For the image I have, I made that in Powerpoint and tried to have both Terra and Sonnet try to generate a less clunky image. They did not succeed.

Week 2: Skills and Project Proposal

The project proposal has since been uploaded to the Project page. When giving it the details for the project proposal, I wanted it to upload the information that was in my Word document. The agent (Claude) was "unable" to find the file two times despite being prompted with the the exact file name. It is interesting how it often asks for more access when in the sandbox that currently exists, although I may be overly suspicious.

For developing the skills file, I had a relatively generic one, with specified details for generating a script to make a figure that would then go into a research paper. The agent (Claude Sonnet 5) was quite easy to generate the content for the file. Then generating figures in the same session was relatively robust. However, consequent sessions that were new did not follow quite as well. I definitely need to write more specifications, as the scripts are quite verbose and overly long compared to scripts that I would write. This occured for both Sonnet 5 and Sol. I'm still quite unfamiliar with skills and not quite sure if it actually is following these skills. I would benefit from spending additional time with the agents to further specify the skills files so that they do not result in overly verbose scripts and making sure it's actually following the skills.

September 14, 2026

Week 1: Site Creation

Since I have no experience with creating websites, Claude Sonnet 5 did the vast majority of the heavy lifting with the formatting and creation of the pages. I had the agent create the site using html, with the original reference files from the class website Astro files. It ended up deleting them. The easter eggs were remarkably easy for it to implement, requiring only a single prompt.

Changing colors or fonts required multiple prompts, and the agent often insisted that the colors had all been changed one way or another when it had not. The insertion of pictures also had a brief hiccup with paths, although this was more likely due to unspecific prompting on my end.

The animation and easter egg pop ups were quite fun to brainstorm and the agents did a great job. It was definitely faster than doing it on my own, and I was quite impressed with how smooth the process was. Log entries and larger text blocks were manually input.
